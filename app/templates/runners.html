Breadcrumb is import-first, with an optional native executor for the built-in collectors. External tools still POST output back to /api/v1/pastes and move jobs through queued → running → done. Native jobs can be claimed by breadcrumb worker or run from a job's page.

Executor mode: {{ executor_mode }} (default off). Set BREADCRUMB_EXECUTOR=inline for an in-process worker, or run breadcrumb worker separately. External tool adapters are opt-in: run one from a job page, or set BREADCRUMB_EXTERNAL_TOOLS=1 for the durable worker to claim adapter jobs. BREADCRUMB_STRICT_MODE=1 disables adapters that cannot be pinned. {% if maintenance and maintenance.maintenance %}
Maintenance mode is on: worker claims are paused{% if maintenance.maintenance_reason %} ({{ maintenance.maintenance_reason }}){% endif %}.{% endif %}

Native collectors accept a JSON options object: ports, http_ports, tls_ports, api_paths, subdomains, nvd_cache, nvd_lookup. External adapters accept only a fixed set: ports, severity, depth, rate and wordlist (ffuf). run now applies to native collectors and installed external adapters; external jobs without an adapter stay queued for their tool to post evidence back. The leadline-recon runner runs the full twelve-phase preset.
