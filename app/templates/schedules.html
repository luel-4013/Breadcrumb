Local re-import schedules

A schedule watches one local folder and imports new files through the normal capture path. There is no URL fetch, no cloud scheduler and no daemon installed by default: run breadcrumb scheduler in the foreground, or call breadcrumb schedule run <name> from cron/Task Scheduler. Identical bytes are deduplicated by content hash.

Files are read as text. Successful imports move to processed/ when that option is on; failed reads/ingests stay in place. Binary files, hidden files and files larger than 25 MB are skipped and reported.
